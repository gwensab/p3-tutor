Context and memory in an agent

From lesson 1.

Where does it live?

HomePut thereLasts
Context (system prompt)Small, always needed, rarely changes (rules, role)One call, rebuilt each time
Message historyThe current conversation and tool resultsOne session; resent on every call
Notes storeSmall facts about a user to reuse later (training status, preferences)Across sessions, if the program saves and reloads
Retrieval storeLarge documents; fetch a few chunks per questionPermanent; only fetched chunks enter the context
Live toolData that changes (calendar)Read fresh each time

Rules of thumb

  • The model sees only the current call's context; it keeps nothing itself.
  • Total input cost = sum of every call's input, because each call re-reads the history.
  • When the history grows: trim old tool results, summarize, drop the oldest, or move facts to notes.
  • Wrong answer and the needed passage is missing from the context: debug retrieval. Passage present: debug the prompt or model.
