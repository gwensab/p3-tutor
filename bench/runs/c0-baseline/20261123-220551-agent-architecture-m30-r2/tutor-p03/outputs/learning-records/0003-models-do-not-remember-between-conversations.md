# Misconception raised: models remember past conversations on their own

Riley assumed a language model automatically remembers earlier conversations, so the makerspace assistant would recall what each student said last week. This was corrected in chat: a model only sees the text in its current context, and anything carried between sessions must be saved by the application and put back into the context.
